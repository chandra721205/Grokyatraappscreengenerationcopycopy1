## ❓ FAQ - Frequently Asked Questions

### **Q: Where do I start if I'm new to this project?**
A: Read `/HONEYMOON_FINAL_DELIVERY_SUMMARY.md` first for a high-level overview.

### **Q: How many destination cards are there?**
A: 18 total (6 per category: Beach, Heritage, Wellness)

### **Q: Can I customize all text elements?**
A: Yes! There are 162 admin-editable text fields across all screens.

### **Q: How do users find real destinations?**
A: Via 51 Google/YouTube browse integration points throughout the app.

### **Q: Where is interest tracking data stored?**
A: localStorage (client-side) + backend API (via POST /api/interests/sync)

### **Q: How do deal notifications work?**
A: Users set budget preferences → System matches deals → Notifications sent when match found

### **Q: What are the purple banners for?**
A: Visual indicators that content is admin-editable.

### **Q: Can I preview changes before publishing?**
A: Yes, the admin editor has a "Preview" button.

### **Q: Is the design mobile-responsive?**
A: Yes, optimized for 375x812px mobile screens.

### **Q: How do I edit filter chip labels?**
A: Admin Dashboard → Honeymoon Editor → Level 3: Filter Chips

## 🗝️ Glossary

**Admin-Editable Content:** Text fields that can be updated via the admin dashboard without code changes.

**Bracket Notation:** Format `[Admin: Your Text]` used to indicate admin-managed placeholder content.

**Deal Alert:** Notification sent to users when packages match their budget preferences.

**Destination Card:** Card component displaying a honeymoon destination template with details, browse buttons, and interest tracking.

**Filter Chip:** Clickable button that triggers Google search for specific category (e.g., "Luxury Resorts").

**Five-Level Hierarchy:** System organizing admin-editable content into 5 priority levels (Headers → Sections → Filters → Primary → Secondary).

**Interest Tracking:** System allowing users to "heart" destinations and receive deal notifications.

**localStorage:** Browser-based client-side storage for user preferences and interests.

**PersonalizedDealsAlert:** Banner component for capturing user budget preferences and enabling deal notifications.

**Purple Indicator:** Visual design element (purple banner/badge) showing content is admin-editable.

**Sub-Category:** One of three honeymoon types: Beach & Island Paradise, Heritage & Luxury Palaces, Wellness & Spa Retreats.

**Template-Based:** Content approach using generic placeholders instead of specific destinations.
