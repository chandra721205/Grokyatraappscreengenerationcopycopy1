## 🎯 USER FLOWS

### **Flow 1: Explore Sub-Categories**

```
User Opens Senior Wellness
   ↓
Scrolls to "Senior Tourism Categories"
   ↓
Taps "🙏 Senior Devotional Yatras"
   ↓
Views Features & Admin Info
   ↓
Taps [Back] to return to main hub
```

**Duration:** ~30 seconds  
**Taps:** 2 (open, back)

---

### **Flow 2: Book Single Service**

```
User Opens Senior Wellness
   ↓
Scrolls to "Care Services"
   ↓
Taps [Book Services] button
   ↓
Selects ☑ Doctor on Tour only
   ↓
Taps [Continue to Details (1 selected)]
   ↓
Fills journey details form
   ↓
Taps [Review Booking]
   ↓
Reviews summary (₹8,000 + tax)
   ↓
Taps [Confirm Booking]
   ↓
Success confirmation
```

**Duration:** ~3 minutes  
**Taps:** 5-7 (main actions)

---

### **Flow 3: Book Multiple Services**

```
User Opens Senior Wellness
   ↓
Taps [Book Services]
   ↓
Selects ☑ Doctor, ☑ Nursing, ☑ Emergency
   ↓
Views total: ₹18,000
   ↓
Taps [Continue to Details (3 selected)]
   ↓
Fills details
   ↓
Reviews booking (₹21,240 with tax)
   ↓
Confirms
```

**Duration:** ~4 minutes  
**Taps:** 7-9 (including selections)

### **Flow 4: Book All Services**

```
User Opens Senior Wellness
```
