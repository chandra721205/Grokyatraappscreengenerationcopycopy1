## 🎭 Interactive States

### Button States
```
Default:  Purple gradient, white text
Hover:    Slightly lighter, shadow increases
Active:   Scale to 0.98
Disabled: Gray, 50% opacity
```

### Card States
```
Default:  White, shadow-md
Hover:    shadow-lg, scale 1.02
Tap:      scale 0.95
Selected: Purple border (2px)
```

### Checkbox States
```
Unchecked: White with gray border
Checked:   Purple background, white checkmark
Hover:     Light purple background on label
```

## 📐 Responsive Breakpoints

### Mobile (< 640px)
```
Grid:      2x2 (2 columns, 2 rows)
Padding:   16px sides
Font Size: 12px-14px base
Cards:     Full width in forms
```

### Tablet (640px - 1024px)
```
Grid:      2x2 (larger cards)
Padding:   24px sides
Font Size: 14px-16px base
Cards:     More spacing between
```

### Desktop (> 1024px)
```
Grid:      2x2 (max-width container)
Padding:   32px sides
Font Size: 14px-16px base
Cards:     Optimal spacing
```

## 💡 Design Rationale

### Why Lavender/Purple/Blue?
- **Lavender:** Calm, academic, trustworthy
- **Royal Purple:** Prestigious, educational institutions
- **Light Blue:** Clear, open, accessible
- **Combined:** Professional yet approachable

### Why 2x2 Grid?
- Mobile-friendly (2 columns fit perfectly)
- Equal visual weight to all pathways
- Easy to scan and compare
- Balanced, symmetrical layout

### Why Separate Forms?
- School groups need safety focus
- Researchers need permit focus
- Different logistics requirements
- Clearer user experience
