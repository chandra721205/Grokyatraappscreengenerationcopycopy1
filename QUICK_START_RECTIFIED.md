## 🔍 Using Google Search Feature

### Where to Find It
- **Main Home**: Header (below search bar) + on each card
- **Explore Page**: Header + on each destination card + map button
- **Category Hubs**: Header + on each tour card + quick action

### How It Works
1. Type your interest in the search bar
2. Click "Google Search" button
3. Opens Google in new tab with your query
4. Discover real destinations
5. Tab back to app to continue

### Example Queries
- Main Home: "tourist destinations india"
- Adventure Hub: "adventure tourism destinations india"
- With search: "beach destinations goa" (uses your input)

## 🏷️ Understanding Placeholders

### What You'll See
Instead of specific destinations, you'll see:
- "Admin-Added Destination 1/2/3"
- "Popular Spot A/B/C"
- "Location X/Y/Z"
- "[Category] Experience/Package/Option"
- "Location to be assigned"

### What This Means
- These are template structures
- Admin will populate with real destinations later
- Use Google/YouTube to find actual destinations now
- Your search preferences will be saved for personalization

## 🆘 Need Help?

### Common Questions

**Q: Why do I see placeholders instead of real destinations?**
A: The app uses admin-managed content. Use Google/YouTube buttons to find real destinations based on your interests.

**Q: How do I book a tour?**
A: Currently, tours are templates. Use search features to discover destinations, then contact admin for booking.

**Q: Can I save my searches?**
A: Search preferences are tracked for future personalization features.

**Q: What if I want a specific destination?**
A: Type it in the search bar and click Google Search to find details.
